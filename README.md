# Blind-Auction-Project
I created this Secret Auction program as part of Day 9 of my 100 Days of Python course. The program allows multiple people to place bids without revealing how much other people have entered. Once everyone finishes bidding, the program compares all the bids and announces the person who offered the highest amount.

The main goal of this project was to get more comfortable working with Python dictionaries, functions, loops, and conditional statements.

How the Program Works

The program asks the user to enter their name.

The user enters the amount they want to bid.

The program stores their name and bid in a dictionary.

The program asks if there are any other bidders.

If there are more bidders, the screen is cleared with blank lines to hide previous bids.

Once everyone finishes, the program finds the highest bid and announces the winner.

Python Concepts I Used

Dictionaries: Stores each person's name and bid amount.

Functions: Finds the person who placed the highest bid.

For Loops: Goes through each bid in the dictionary.

While Loops: Keeps the auction running until everyone finishes bidding.

If/Else Statements: Determines whether to continue the auction or announce the winner.

Variables: Keeps track of the highest bid and the winning bidder.

User Input: Allows people to enter their names and bid amounts.

How to Run the Program

Download or clone this repository.

Make sure Python is installed on your computer.

Open the project in PyCharm or another Python editor.

Make sure main.py and art.py are in the same folder.

Run main.py.

Enter your name and bid amount.

Continue adding bidders until everyone has finished.

The program will announce the winner.
